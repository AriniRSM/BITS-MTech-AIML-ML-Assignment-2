
# BITS M.Tech AIML - Machine Learning Assignment 2

## Project Title
Credit Card Default Prediction Using Machine Learning Classification Models

## Problem Statement
The objective is to develop and evaluate five machine learning
classification algorithms to predict whether a credit card
customer will default on their next payment.

## Dataset
UCI Default of Credit Card Clients Dataset

## Classification Type
Binary Classification

## Models
1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors
4. Gaussian Naive Bayes
5. Support Vector Machine

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Streamlit
